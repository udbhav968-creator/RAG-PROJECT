# Contributing to Industrial RAG Engine

Thank you for your interest in contributing to **Industrial RAG Project**!

## 🚀 Guidelines

1. **Fork & Branch**: Create a feature branch (`git checkout -b feature/amazing-feature`).
2. **Coding Standards**: Follow PEP 8 guidelines and include type hints for FastAPI/Pydantic schemas.
3. **Unit Tests**: Ensure all unit tests pass (`python -m unittest tests/test_rag.py`).
4. **Commit Messages**: Follow Conventional Commits format (e.g., `feat: ...`, `fix: ...`, `docs: ...`).

## 🧪 Testing

Run test suite before opening a Pull Request:
```bash
python -m unittest tests/test_rag.py -v
```
